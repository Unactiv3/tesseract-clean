# DEADPIXEL // STUDY HALL

An immersive, pixel-themed study application built with vanilla HTML, CSS, and JavaScript. Features an intro sequence with glitch effects, dashboard, subject tracking, focus mode (Pomodoro), AI tutor, and a pixel-finding mini-game.

## Features

- **Intro Sequence**: Boot animation → Glitch welcome → Jumpscare → Welcome back
- **Dashboard**: Track progress, study streaks, and subject cards
- **Subjects**: C Programming, Python, Mathematics, AI with chapter tracking
- **Notes Library**: Browse and view notes with corrupted file effects
- **Focus Mode**: Pomodoro timer with distraction meter and ambient quotes
- **AI Tutor**: Interactive chat with context-aware responses
- **Pixel Lab**: Find the dead pixel in a grid grid-game
- **Achievements**: Unlock XP-based achievements
- **Ambient Glitches**: Cursor trails, screen tears, popups, and inversion effects

## Getting Started

```bash
cd deadpixel-study-hall
npm run dev
```

Open `http://localhost:3001` in your browser.

## Deployment

This app is configured for Vercel deployment. The root `vercel.json` includes a rewrite rule for `/deadpixel-study-hall/*`.
